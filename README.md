# 🔐 React Supabase Login

Welcome to **React Supabase Login**, a modern and scalable authentication system built with **React**, **TypeScript**, **Supabase**, **Tailwind CSS**, and state management powered by **Redux Toolkit Query**.  

This project aims to provide a clean, performant, and developer-friendly login/authentication experience.

---

## 🚀 Features

- 🔑 User authentication with **Supabase** (signup, login, logout, password reset)  

- ⚡️ Built with **React 18** + **TypeScript** for type safety and reliability  

- 🎨 Stylish and responsive UI using **Tailwind CSS**  

- 🔄 Global state management using **Redux Toolkit** and **RTK Query** 

- 🛠️ Code quality ensured with **Prettier** formatting  

- ⚙️ API calls optimized and simplified with **Redux RTK Query**

## 📥 Installation

1. Clone the repo 

        git clone https://github.com/frau-azadeh/reactsample.git

2. Navigate to the project directory

        cd reactsample

3. Install dependencies

        npm install

4. Create a .env file in the root and add your Supabase credentials:

        VITE_SUPABASE_URL=your-supabase-url
        VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

## ⚙️ Usage

    Start the development server:

        npm run dev

    Open your browser and visit http://localhost:5173
